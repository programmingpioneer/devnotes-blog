## What are Hooks?

Hooks are functions that let you **hook into** React state and lifecycle features from function components. Before hooks, this logic required class components.

## useState

The most basic hook. It returns a pair: the current value and a setter function.

```tsx
const [count, setCount] = useState(0);
```

When you call `setCount`, React re-renders the component with the new value. Never mutate state directly — always use the setter.

## useEffect

For side effects — data fetching, subscriptions, manual DOM mutations.

```tsx
useEffect(() => {
  const id = setInterval(() => setCount((c) => c + 1), 1000);
  return () => clearInterval(id);
}, []);
```

The return function is **cleanup** — it runs before the next effect and on unmount.

## Rules of Hooks

1. Only call hooks at the **top level** — never inside loops, conditions, or nested functions.
2. Only call hooks from **React function components** or **custom hooks**.

Violating these breaks the order React tracks state internally.

## Custom Hooks

Extract reusable logic into a function starting with `use`:

```ts
function useLocalStorage<T>(key: string, initial: T) {
  const [value, setValue] = useState<T>(() => {
    const stored = localStorage.getItem(key);
    return stored ? JSON.parse(stored) : initial;
  });

  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);

  return [value, setValue] as const;
}
```

> **Rule of thumb:** If your component has non-trivial state logic, extract it into a custom hook. Your component stays readable, your logic becomes testable.

## Recap

- `useState` — component-local state
- `useEffect` — side effects + cleanup
- Custom hooks — reusable stateful logic
